# 加密笔记

这里保存的是加密后的笔记、可离线使用的浏览器阅读器和本地解密脚本。没有正文或密码的明文副本。

## 用 DeepSeek Harness（dsh）接着分析

AI 模型不能直接把密文当作笔记理解。先在公司电脑本地解密为 Markdown，再让 dsh 读取该文件。

1. 克隆这个公开仓库（或下载仓库 ZIP 并解压），进入仓库文件夹。
2. 将密码文件单独放在仓库之外的本机私人目录。密码须为 UTF-8 单行文本，末尾可以有一个换行。
3. 使用 Node.js 18 或更新版本运行以下命令，把密码路径换成本机的实际路径：

```sh
node decrypt.mjs --password-file /path/to/local-password.txt --output ../private-notes/notes.md
```

脚本会按需创建输出目录，拒绝覆盖已有文件。输出位于仓库之外；不要将明文或密码上传。无需把密码文本告诉 dsh，也无需打印密码文件内容。

也可以省略 `--password-file`，按终端提示静默输入密码：

```sh
node decrypt.mjs --output ../private-notes/notes.md
```

密码不会回显，也不会作为命令行明文参数保存到历史记录。脚本不联网，不依赖第三方包；新建文件在支持 POSIX 权限的系统上为仅当前用户可读写（0600）。Windows 的实际访问权限由本机账户与 ACL 设置决定。

4. 向 dsh 提供解密后 Markdown 的完整路径，并使用下面的接续提示词：

> 请先读取本机的 `<notes.md 完整路径>`，据此继续梳理文档中的报告分析思路。请沿用文档中的口径、数据限制和已确定的报告主线，先整理章节与页面结构，再细化可执行的分析过程。当前没有真实业务数据，请勿虚构数据；示例必须标明是示例。无需读取或输出密码文件。

加密保护的是公开仓库中的内容。dsh 读取解密后的明文时，内容会进入其所连接模型的上下文，请按公司对该工具和模型的使用规定处理。

## 在公司电脑阅读

1. 打开仓库中的 `encrypted-notes.html`，点击 **Download raw file / 下载原始文件**，保存为 `.html` 文件。不要复制 GitHub 代码预览页面。
2. 用 Edge、Chrome 或 Firefox 打开下载后的文件。无需安装软件，文件中已经包含全部加密内容；断网也可以阅读。
3. 输入另行保存的访问密码，点击“解密阅读”，或按回车。
4. 阅读结束后点击“锁定”或关闭页面。密码不会保存到浏览器存储中。

密码不在这个公开仓库中，请从独立的私人渠道获取。请勿把密码写入仓库、Issue、提交说明或公开评论。

## 保护方式

正文使用 AES-256-GCM 加密；密钥由密码经 PBKDF2-HMAC-SHA256、600,000 次迭代生成。每次构建生成新的 16 字节随机盐和 12 字节随机 IV，认证标签为 128 位。

浏览器阅读器的解密只在当前浏览器内进行。阅读器不使用第三方资源，不发起网络请求；正文在禁止脚本的沙箱中显示。密码错误或密文被修改时不会显示正文。锁定会移除正文与密码输入，并释放当前页面对解密数据的引用；浏览器负责管理内存，无法保证立即擦除所有内存副本。

公开仓库中的密文可以被任何人永久下载，因此密码应足够长且随机。修改密码并重新加密后，旧版本的密文仍可能保留在 Git 历史或他人的副本中，旧版本仍需用旧密码保护。文件名、提交时间、文件大小以及本说明是公开的。

如浏览器或公司策略禁止打开本地 HTML / 使用本地加密能力，请按公司的设备与信息管理规定处理。
